# QubitSphere — MVP Scope

## Objective

Build a convincing working vertical slice within the hackathon
timeline.

The MVP must prioritize functionality and demo quality over feature
quantity.

---

# MUST HAVE

## 1. Dashboard

The learner can see:

- current learning progress
- completed concepts
- weak concept
- recommended next lesson

## 2. Learning

At least the following concepts should be represented:

- Qubit
- Superposition
- Measurement
- Quantum Gates
- Entanglement

## 3. Circuit Lab

The learner can:

- create a circuit
- add gates
- remove gates
- modify circuit operations
- run the circuit
- see circuit representation

## 4. Circuit IR

All circuits must use a framework-neutral internal representation.

## 5. Quantum Simulation

The system must execute circuits through a deterministic
quantum simulator.

## 6. Visualization

At minimum:

- measurement probabilities
- histogram
- circuit representation

If time permits:

- statevector
- Bloch sphere

## 7. AI Tutor

The AI can:

- explain a concept
- explain a selected gate
- explain the current circuit
- explain simulation results
- provide hints
- identify common mistakes
- recommend a next learning activity

## 8. Assessment

The learner can complete:

- a quiz
- at least one circuit challenge

The system records a score.

## 9. Progress

The system records basic:

- concept mastery
- challenge attempts
- scores
- completed lessons

---

# SHOULD HAVE

- Bloch sphere
- code editor
- algorithm templates
- adaptive recommendation
- additional framework adapter
- richer visualizations

---

# NOT IN MVP

- full production authentication
- enterprise instructor dashboard
- full QPU management
- complete framework parity
- 20+ quantum algorithms
- advanced noise simulation
- AR/VR
- blockchain
- unnecessary IoT features
- complex enterprise infrastructure

---

# MVP Algorithms

## 1. Bell State

Purpose:

Demonstrate:

- superposition
- entanglement
- measurement

## 2. Deutsch-Jozsa

Purpose:

Demonstrate:

- quantum algorithm structure
- oracle concept
- quantum/classical comparison

## 3. Grover

Purpose:

Demonstrate:

- amplitude amplification
- search
- algorithmic quantum behavior

---

# Definition of Done

The MVP is considered successful when a judge can:

1. Open QubitSphere.
2. Learn a concept.
3. Build a circuit.
4. Run the circuit.
5. View a real simulation result.
6. Ask the AI about the result.
7. Receive an explanation grounded in the circuit.
8. Complete a challenge.
9. See progress update.
